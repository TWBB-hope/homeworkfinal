期末大作业开发记录，配合报告第一、三部分使用。所有时间戳与 `git log` 一致，可随时核对。
基线：课堂作业八的自主实践原型 `homework8/practice/`（单页看板，jQuery 筛选＋localStorage 预约＋Chart.js 两类图＋Three.js 场馆场景）。
本次把它扩展成四个独立页面的完整作品，并补齐作业要求里原型没有的部分。

## 二、开发中真实遇到的问题与处理（对应报告第三、六部分）

| 编号 | 现象 | 原因 | 处理 |
| --- | --- | --- | --- |
| B1 | 改了 `facilities.json` 刷新后数字不变，一度以为降级代码没生效 | 浏览器缓存了上一次成功的 JSON 响应，`$.getJSON` 默认允许缓存 | `common.js` 增加 `C.getJson()`，请求带时间戳参数绕缓存；`README` 的"改完刷新即见"这才成立 |
| B2 | 分析页筛选到 0 条后再放宽条件，控制台抛 `Cannot read properties of null` | 空结果时用提示文案替换了 `.chart-box` 内容，canvas 已不存在，重建图表时按 `#weekChart` 找容器找不到 | 改为按容器 id（`#weekBox` 等）重建 canvas，并在重建后再建图表；同时区分"主表为空"与"筛选后为 0"两种文案 |
| B3 | 添加预约成功提示"还剩 1 个名额"，实际该时段已被自己占满 | 剩余名额在保存之前算，漏算了自己刚提交的这一条 | 保存之后重新调用 `stats()` 计算，提示与下拉框里的"剩 N 个名额"才一致 |
| B4 | 预约时间显示为凌晨 02:00（本机是 10:00） | 用了 `toISOString()`，那是 UTC 时间 | 改成本地时间逐段拼接 `YYYY-MM-DD HH:mm` |
| B5 | 首页"今日开放速览"里自由进场场馆也显示"去预约" | 文案未区分场馆类型，会诱导无效操作 | 按 `bookable` 分别给"去预约"与"查看场馆信息" |
| B6 | 提示语"请在右侧选择时段"在手机上不成立 | 手机是单列布局，表单在下方 | 改为"请在下方预约表单里选择时段" |
| B7 | 一致性自检第 4 条写死"14 个整点时段逐一核对" | 数据一变这句话就可能变成假话 | 改成不写死数量的表述 |
| B8 | 三维页在 Three.js 缺失时停在"建筑含义加载中…" | `boot()` 直接 return，后面的文字内容都没渲染 | 增加 `renderTextFallback()`：图例、编码说明与文字版场馆清单照常给出 |

## 三、风险清单（含已发生与仍存在的）

| 编号 | 风险（具体场景） | 影响 | 应对措施 | 现状 |
| --- | --- | --- | --- | --- |
| R1 | 验收机房断网或 CDN 被拦截，图表与三维区空白，会被判"功能未实现" | 直接扣可视化与三维两项分 | 库优先 CDN、失败自动改读仓库内 `vendor/` 同版本副本；两者都缺时页面给出红色提示且文字结论照常渲染（已实测，见 B8 与截图 20、21） | 已缓解 |
| R2 | 同一指标在四个页面各算一遍，改一处忘一处导致数字对不上 | 可视化"数据不诚实"，第四部分扣分 | 结构性消除：占用率与人次只存在于 `CampusData.stats()` 一处；分析页再放 5 条自检，两条独立路径互算，不过就标红并提示 | 已缓解 |
| R3 | 浏览器缓存 JSON，演示时改了数据看不到变化，临时排查浪费时间 | 现场演示节奏被打断 | 请求带时间戳（B1）；`README` 故障表里给出 Ctrl＋F5 兜底 | 已解决 |
| R4 | `localStorage` 在隐私模式或被禁用时抛异常，点"添加预约"直接卡死 | 错误处理不达标 | 读写全部包在 `try/catch`，失败给红色提示且说明"本次改动未保存"，列表仍按存储真实内容渲染（已用覆写 `setItem` 抛 `SecurityError` 实测） | 已缓解 |
| R5 | 现场随机指一段代码讲不清，会被视同非本人完成 | 直接影响成绩 | 提交说明写"做了什么＋为什么"；本文件第二节的 8 个问题都是我自己踩的，按编号能复述来龙去脉；重点准备 `data.js` 的派生函数与 `facilities.js` 的 `validate()` | 持续 |
| R6 | 三维渲染循环在页面切走后仍在跑，回到主页面时卡顿 | 被误判为主页性能问题 | `visibilitychange` 与 `pagehide` 停／启 `requestAnimationFrame`；自查项："三维页停留 1 分钟后切回主页仍流畅" | 已缓解 |
| R7 | 数据是静态快照（统计截至 2026-09-19 14:00），深夜演示时"当前时段无场馆开放"看起来像 bug | 观感差 | 首页速览允许手动切换整点时段，并在不在开放时段时明确说明"已默认预览 08:00-09:00"；折线图今日点标注统计截至时间 | 已缓解 |
| R8 | 预约只存在浏览器里，换一台电脑或清缓存就没了，无法体现"管理" | 功能深度受限 | 明确写进局限性（报告第七部分）：这是无后端的必然限制，改进方向是把 `slotBookings` 换成教师提供的接口 | 存在，已记录 |

## 四、范围控制：明确不做

后端与数据库、登录与权限、React／Vue 等未讲授框架、真实支付与短信通知、地图 API 定位、
外部三维模型文件（只用代码生成的几何体）、图表库与三维库之外的新库。
写在这里是为了防止在剩余时间里继续加功能而牺牲质量。
